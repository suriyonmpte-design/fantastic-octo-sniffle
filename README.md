# fantastic-octo-sniffle

ระบบต้นแบบ **Prime Tech Enterprise Pattaya – Workflow Full Service**

## Quick Start
```bash
python3 src/enterprise_workflow.py --db data/workflow.db seed-demo
python3 src/enterprise_workflow.py --db data/workflow.db dashboard
```

หรือรันสคริปต์เดียว:
```bash
bash tools/run_demo.sh
```

## Commands
- `init-db`
- `add-client`
- `add-project`
- `add-task`
- `update-task`
- `dashboard`
- `seed-demo`
